🚀 Conheça Mais — Telegram Offers Bot

Bot desenvolvido em Python com o objetivo de automatizar a busca, organização e divulgação de ofertas de produtos em canais do Telegram, utilizando links de afiliados.

O projeto busca simplificar o processo de divulgação de promoções de marketplaces, conectando oportunidades de compra a potenciais consumidores.

🎯 Objetivo do projeto

Desenvolver uma solução automatizada capaz de identificar ofertas em diferentes marketplaces, trabalhar com links de afiliados e publicar as promoções em um canal do Telegram.

🛒 Marketplaces planejados

Shopee

Amazon

Mercado Livre

As integrações serão implementadas conforme a disponibilidade e as permissões das APIs e ferramentas oficiais de cada plataforma.

⚙️ Tecnologias utilizadas

Python — linguagem principal.

python-telegram-bot — integração com a API do Telegram.

python-dotenv — gerenciamento de variáveis de ambiente.

Git e GitHub — versionamento e documentação do projeto.
